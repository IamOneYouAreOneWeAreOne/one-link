Verify before you trust

Download the artifact, the matching .sigstore bundle, and SHA256SUMS from the GitHub release. Then run: 

bash scripts/verify-release.sh ./one_link-0.20.7.tar.gz

The script checks the SHA-256 against the signed manifest and verifies the Sigstore signature was produced by One Link's GitHub Actions release workflow from the matching tag. Any mismatch refuses the install and tells you why.

If you don't trust the script either, the underlying check is just python -m sigstore verify identity with the workflow identity pinned. Run it yourself.

What's inside

  • X25519 + Ed25519 mutual handshake. ChaCha20-Poly1305 framed wire protocol.
  • Signal-style Double Ratchet for forward secrecy + post-compromise security on every channel.
  • 8-digit transcript-bound SAS pair flow. 5-minute pair TTL. Deny-by-default capability gate after pair.
  • Group-chat sender chains with sliding-window OOO support + Ed25519-signed messages.
  • At-rest encryption ON BY DEFAULT (no passphrase prompt). DPAPI on Windows binds the data root key to the user's login credentials.
  • WebRTC browser-as-peer transport with cryptographically bound DTLS-SRTP fingerprint (signed answer envelope).
  • BLAKE3-verified content-defined chunking for fast large-file sync. Native-code accelerator with SHA-256 sidecar integrity check.
  • mDNS LAN discovery + optional rendezvous + relay for cross-network. Hardened tier (Tor / DHT) on roadmap.
