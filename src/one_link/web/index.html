Privacy

On: paired devices skip the per-capability prompt and get full access. Off: you approve each new pairing's reach. Trust costs nothing until it does.

Encrypts your local database at rest. Set the ONE_LINK_PASSPHRASE environment variable before launching One Link. It's a 2014 vibe, but it works.

How pairing works

When you pair a device, both screens show the SAME 6-digit code (a SAS). If they match, the connection is authenticated and end-to-end encrypted from that moment on. If they don't match, somebody's intercepting. Say no.

Tip: tap the speaker icon to read the SAS digits aloud. Handy when you're confirming over a phone call and don't trust your typing.

Reach devices across the internet?

Right now One Link only finds devices on the same Wi-Fi network. That's perfect for household use — nothing else to set up.

To reach devices in other locations (a laptop at home from a coffee shop, family across town), you need a tiny relay called a rendezvous. It only carries signed presence beacons — never your messages or files.

How to set one up (advanced)
  • Use a rendezvous a friend or community is running — paste their URL into Settings → Rendezvous URLs.
  • Run your own — free, ~5 minutes, see RENDEZVOUS_DEPLOY.md in the repo.
