What this is

This is a browser-as-peer One Link node. Your identity lives in OPFS (origin-private storage); no daemon, no account, no cloud. It's separate from the desktop daemon you may also be running — both are independent peers that can connect to each other once you pair them.

Networking, pairing, chat, and file transfer arrive in subsequent ships. v0.16.0 only provisions identity.

Identity actions

Reset wipes this device's identity from OPFS. After reset, next reload generates a fresh keypair. You can't recover an old identity from a new one — back it up first via Export if you care about message continuity.
